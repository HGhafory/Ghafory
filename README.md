# Academic Portfolio

A free, responsive academic portfolio website designed for GitHub Pages.

## Customize
1. Open `index.html`.
2. Replace the placeholder text with your academic information.
3. Put your CV in this folder and name it `cv.pdf`.
4. Replace `YOUR PHOTO` with an image if desired.
5. Upload the folder to a public GitHub repository and enable GitHub Pages.

## Suggested repository name
`yourusername.github.io`

Then your site will be available at:
`https://yourusername.github.io/`
